# 猜你喜欢：文化卡片重建

2026-10-15。替代旧四题问卷与画像编辑流程。

## 新流程

选择领域（音乐、电影、书籍、都可以）→ 选择真实对象 → 简洁预览 → 直接开始平行人生。一个选择即可继续；全部可退出，不要求完成固定题数。每张卡片可标记喜欢、想了解，或不认识/跳过。可持续保存喜欢和想了解，不受单轮查询数量约束。每轮默认选择最近的最多三个喜欢、一个想了解，预览中可更换，其他收藏继续保留。想了解不转成既有喜好；跳过不保存为负向画像。

初始卡片是编辑选取的多领域搜索起点，逐项通过 Qloo /search 解析，严格要求类型和规范化名字一致后才展示。初始对象不是个性化推荐，界面明确说明。用户搜索可查看实际返回的同类型候选，自行选择具体对象。可切换领域、搜索、换一组；不要求强记英文名字，不提供未经来源核实的中文翻译、图片或性格说明。

已有结构化起点或已解析的实体会作为搜索输入带入；可唯一确认同名实体时自动带入喜欢选择。没有重新要求用户填写同一内容。尚未解析的自然语言若含条件，确认卡片时解析一次来保留约束；已解析意图直接复用。原输入文字不改写。明确时间、预算等条件仍走现有确认和严格检查。

## 与平行人生的连接

喜欢 → 熟悉版本；Qloo 关联对象 → 邻近版本；想了解 → 主动新起点版本。只选择想了解时，首版名称改成“想尝试的我”，不会称为已有爱好。卡片确认传递服务端已发行的真实 ID；实际发现阶段再次检查 ID 在真实查询结果中，不能由浏览器伪造推荐身份。

不再调用旧画像模型来生成名称、简介和四组标签，也不把卡片选择转换成描述后再做一次模型解析。旧画像 API 保留兼容，但新界面不再使用。明确选择现保存在私有 SQLite，支持同一浏览器跨服务重启恢复；反馈仍限当前会话，没有长期负向学习。详见 [本地内容库](local-library.md)。

## 实测接口边界

2026-10-15 分别尝试无兴趣信号的 artist/movie/book Insights 列表，三次均 HTTP 400。因此新版不假设无信号文化目录可用，采用实体搜索。原始试验仅用于错误状态核验，凭据未输出。

浏览器实际解析并展示 Miles Davis、Beyoncé、Björk 三个音乐人；完成喜欢/想了解/跳过到预览，再直接开始检索。卡片名字来自实际响应，不硬编码 Qloo ID。取样范围仍较小，后续应扩展经验证的中文与不同文化背景起点，而不是把当前编辑样本当成全球偏好覆盖。

## 保护与测试

新卡片接口复用会话、CSRF、同源检查、异步任务和配额。单次卡片加载最多追加 12 次网络尝试，整个会话仍最多 40 次；鉴权/额度/限流/网络故障停止继续尝试其他编辑查询。本地浏览会将展示对象及已有选择登记到会话用于身份验证；取消旧目录 120 项门槛，避免较大的兴趣库挡住新对象加载，在线取样仍受会话请求预算限制。SQLite 保存必要对象字段，不保存整份原始记录。未知实体、伪造选择、重复 ID、过量选择、敏感输入被拒绝。

81 项 Python 测试和 9 项前端探索策略场景通过。覆盖真实类型约束、编辑搜索不得用无关结果替代、伪造 ID、尝试意向不升级为喜欢、已有预算/独立书店要求保留、鉴权故障不跨查询重复尝试。1～2 分钟是交互设计目标，尚未经过用户计时研究。

浏览器端已验证：Miles Davis 选择喜欢、Björk 选择想了解、Beyoncé 跳过后，预览保留两种明确意向；一次确认直接生成三个版本，各有 3 个实际地点候选。想了解对应的新版本与熟悉版展示集合本次无重合；这不是满意度提升的证明。私有截图：.qloo-private/stage3/taste-cards-preview.jpg 与 taste-cards-rebuilt.jpg。

后续验收补充：初始书籍卡片按实际出版年份选取代表记录，并展示实际 disambiguation 消歧信息；多条同名结果不自动确认已有喜好。卡片浏览独立限制为每分钟 10 次，避免浏览消耗发现流程的 6 次任务槽位；网络总预算仍为会话 40 次。客户端对相同卡片页缓存 5 分钟。

最终多领域与手机验收：已有 Miles Davis 自动带入喜欢，跳过领域题；初始展示 6 张不同对象卡片，书籍附带实际年份与作者消歧文本。390px 视口无横向溢出，继续按钮位于视口内（top 742 / bottom 787，视口高 844），选一个即可操作。
