# 本地文化内容库

首页现在直接提供可浏览、可点选的真实文化对象。用户可持续收藏“喜欢”和“想了解”，再点选城市、场所与范围，直接进入平行人生。兴趣库不受每轮查询数量限制；每轮默认使用最近的最多 3 个喜欢和 1 个想了解，展示实际起点并允许更换。探索只读取子集，不覆盖其余收藏。可额外排除酒店、商场、工作室或景点；这些是用户条件，不是 Qloo 已证明的用户属性。自然语言入口仍可使用；预算、时间等尚未验证的硬条件继续保留检查。

## 首批真实导入与验收

2026-10-15，执行 60 次定向 Qloo `/search` 请求，导入 57 个对象：20 位音乐人、20 部电影、17 本书，以及接口实际返回的 235 条别名。3 个起点未找到满足名称和类型核验的对象，没有用近似结果填充。编辑样本只用于发现入口，不代表用户兴趣或全球覆盖。

浏览器验证了本地卡片展示、点选后刷新恢复、服务进程重启后恢复，以及 ABBA“喜欢”加 Amélie“想了解”进入三个平行人生版本；每个版本实际返回 3 个地点候选。验收所加的选择已移除。89 项 Python 测试、9 个前端策略场景通过，测试包含 SQLite 过期、隔离、完整查询上下文缓存、参数化搜索和重启恢复。

## 数据结构和保存边界

私有文件：`.qloo-private/cityplay.sqlite3`，目录权限 0700、数据库 0600；已忽略 Git/Docker，不提供静态下载。数据库扫描未发现当前两项 API Key。

- `entities`：实际 ID、规范名称、类型、消歧文本、出版年份、来源、取得和过期时间。
- `aliases`：只保存接口实际提供的语言与别名；不自动编造中文译名。
- `choices`：浏览器身份下的喜欢、想了解；不是性格推断。保存至主动清空或移除，内容库过期不删除用户明确表达的选择。
- `snapshots`：同一浏览器、同一完整条件下的已筛选结果或平行人生版本；不存整份原始响应或密钥。

内容库默认有效期 1 小时；查询快照 5 分钟，每个身份最多 100 条。读取/写入时清理相应过期记录，过期内容不再展示。快照命中明确标示 SQLite 来源，不伪装实时请求。无结果可短暂缓存；接口错误和待补充输入不缓存。场所、范围、口味、排除项、反馈等变化会改变查询上下文。反馈仍只在当前服务会话中有效，尚未实施长期负向学习。

浏览器使用 HttpOnly、SameSite cookie 标识私有选择；公开 HTTPS 模式使用 Secure。不是账号体系，不支持跨设备同步。清除 cookie 将失去原身份访问能力。接口沿用同源、CSRF 与服务端 ID 验证。

## 使用与维护

首页空关键词浏览不调用 Qloo。输入关键词点击“搜索”直接发起有界 Qloo `/search` 查询：本地匹配先显示，再按实际 ID 合并在线候选，标明来源；中文检索命中仍取决于真实名称和别名。在线失败保留本地匹配并明确提示。清空关键词恢复浏览；“发现更多”用于补充编辑选取的起点。新组合的文化关联和地点推荐继续查询真实 Qloo，短期重复请求可命中快照。原“猜你喜欢”也优先使用本地内容。

手动补充首批编辑起点：

```sh
PYTHONPATH=src python3 scripts/seed_cultural_library.py --limit 60
```

该命令消耗真实配额；没有后台无限同步。当前 57 个对象过期后应显式补充，不保证长期离线可用。账户附加条款的长期缓存/展示授权仍未核实，当前 TTL 是技术保存策略，不代表已取得数据授权；不导出、提交或公开分发 Qloo 数据集。外部部署继续暂缓；未来部署需要私有持久卷和清理策略。

后续可在验证数据与授权后扩展不同文化背景的样本、主动兴趣分支、持续反馈。无障碍、健康或特殊人群需求不能仅凭文化标签推断场所可用性，应另接可核实来源。

首页发现流已与普通搜索缓存分离：discovery 表只标记编辑精选对象，普通缓存仍可搜索。无精选时展示编辑搜索起点，点击后才解析并由用户确认，避免历史查询结果污染首次体验。详见 [可用性修复](usability-repair-validation.md)。
