# 首次使用问题修复与验收

2026-10-15。针对 `first-use-usability-audit.md` 的高优先问题，本轮修改代码并复测；没有变更公开部署范围。

## 本轮完成

- 统一退出结果模式的编辑入口。空结果的换场所、调范围、通用修改条件都使用同一状态切换，修复 details 打开后仍被父级 CSS 隐藏；移除 editRequest 中未定义的 review。
- 根据实际 rejection_counts 区分“没有匹配地点”和“找到了候选但无法核实预算/即时营业/行程时间”。后者提供保留要求编辑，或由用户明确选择仅取消这些未核实硬要求；其他要求和排除项不变。没有自动宽松过滤。
- 城市冲突提供明确按钮：切换到描述中的城市并重新解析，或保留页面城市修改描述。冲突未解决时，前端禁止确认，服务端也拒绝发现请求；卡片确认不能绕过冲突。明确预算、营业、市界和新颖要求继续保留。
- 首页按城市、文化搜索/猜你喜欢、开始探索组织；开始按钮提前并在手机滚动时保持可见，高级场所/范围/排除设置折叠。显示“示例中心”，距离不再容易被误认为设备定位。
- 搜索按实际名称及已验证别名进行精确归组，不采用模糊身份猜测；相近或其他候选保留但折叠，并明确不代表同一对象。猜你喜欢沿用同一判断。
- SQLite 新增 discovery 身份表，区分编辑精选与普通搜索缓存。普通搜索仍能查到缓存，默认首页不再按字母混排全部历史查询结果。旧编辑种子根据已有来源迁移；没有可用精选时提供明确标注的编辑搜索起点，点击才检索，不假装已解析或个性化推荐。
- 收藏/取消后恢复原按钮焦点，本轮起点更换后恢复对应复选框焦点。
- 地点卡直接展示 Qloo 简介原文、网站核实状态和外部地图导航。版本卡直接展示实际文化起点/桥梁及返回的场所类别组合，不编造氛围、人格或喜欢概率。邻近版生成期间提示首批地点可先查看。

## 验证

99 项 Python 测试通过。新增用例覆盖编辑发现/缓存隔离、城市冲突元数据、卡片确认保留冲突与服务端禁止绕过。前端新增回归覆盖可见编辑状态、原条件保留、只放宽实际未核实项、姓名及真实别名匹配、稳定排序和焦点恢复；原搜索、地图、起点及9个探索策略场景通过。

- 390×844 视口文档宽390px，开始按钮 top=637px、猜你喜欢 top=590px；原走查分别是2052px、2110px。此值仅为当前页面状态的布局测量，不是用户转化率。
- 搜索迈克尔杰克逊：正确姓名优先可见，本页5个其他候选默认折叠。收藏后 activeElement 为原 BUTTON，而非 BODY；验收收藏已取消。
