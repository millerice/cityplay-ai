# 兴趣库与本次探索分离

2026-10-15。取消兴趣库中“三个喜欢、一个想了解”的产品上限。SQLite 保留全部明确选择，新增想了解不替换之前的想了解。取消收藏仅移除该项；跳过卡片不推断负向偏好。

每次探索仍使用有界的文化信号：最多三个喜欢用于熟悉版本，一个想了解用于主动尝试的另一版；没有喜欢时，选一个想了解也可以开始，不能称为既有喜好。这是当前工作流的成本与展示范围，不宣称为 Qloo 官方上限。

首页和猜你喜欢预览明确显示“本次从这些口味出发”。默认优先最近选择的喜欢及想了解，未声称已进行语义相关性排序。通过“更换本次起点”可在全部收藏中点选：超过本轮容量时替换最早的本轮同类起点，收藏本身不变。全部取消本轮起点时不允许空请求，选一个即可继续。

猜你喜欢卡片点选立即保存；关闭后重新打开恢复兴趣库。运行确认只合并明确起点，绝不整体替换兴趣库；已经存在且意向不变的对象不会仅因查询而更新时间，因此探索不改变“最近选择”的排序。请求只提交本轮少量 ID，不随收藏增长扩大 Qloo 信号和请求体。

新增合成测试覆盖多项喜欢和想了解持久化、运行子集不覆盖收藏或排序、过量运行信号拒绝且不改动收藏、默认起点选择及想了解不提升为喜欢。浏览器实际验证保存四个喜欢和两个想了解、从全库更换本轮起点、猜你喜欢恢复六个收藏并接受第五个喜欢。UI 验收收藏会在结束时移除。

后续的按场景选择、多次体验反馈与长期学习尚未实现；当前个性化仍由明确表达和真实 Qloo 查询提供。

验收：96 项 Python 测试通过，默认起点选择、地图定位与 9 个前端策略场景通过。手机 390px 视口无横向溢出；验收加入的 6 项收藏已移除，保留可继续使用的真实内容库。
