# 统一文化搜索

2026-10-15。首页“搜索本地”改为“搜索”，提示“搜索音乐人、电影或书籍”。输入关键词并提交会直接调用服务端 `/api/taste/cards` 异步任务，由服务器通过已有固定 Hackathon API 地址调用 Qloo `/search`。Key 不进入浏览器。全部领域分别以实际类型 artist、movie、book 查询，每类 take=5；可切换单独领域。查询仍受已有同源、CSRF、敏感输入、任务并发和会话配额约束。

先读 SQLite 匹配并显示，再按实体 ID 合并 Qloo 候选，重复 ID 使用在线返回元数据。卡片明确区分“本地缓存”和“Qloo 搜索”；在线搜索可能命中原有 5 分钟传输缓存，不标成强制实时结果。返回候选供用户主动确认，不自动把近似对象当成用户所指作品。

在线结果直接展示，不重新经过本地字符串过滤：规范名称、跨语言别名或相关作品可能不包含输入关键词。当前合并结果在内存中分页，翻页不发起新的 Qloo 请求。清空关键词恢复本地浏览；输入关键词时“重新搜索”重试当前查询。Qloo 返回为空、部分失败或整体失败有相应提示；失败不清空已取得的本地匹配或用户兴趣库。

候选通过既有写入层存入私有 SQLite，保留来源及 1 小时有效期，不能据此假设长期保存授权。“发现更多”继续用于没有关键词时的编辑起点补充。

浏览器真实验证：搜索 Daft Punk，返回 15 个实际候选，包含音乐人、电影、书籍；Electroma 这类名称不包含查询词的候选也保留。已验证分页和音乐人候选的收藏/取消，验收选择已撤销。搜索返回相近作品并不证明身份相同，需要用户选择具体对象。

97 项 Python 测试通过，HTTP 测试覆盖真实代码链路的合成搜索响应、缓存和服务端 ID 收藏。前端新增测试覆盖本地先展示、按 ID 合并、来源、重复提交、名称不含关键词、部分/整体失败、空关键词和敏感输入；原地图、探索策略、起点选择测试通过。
