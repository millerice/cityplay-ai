# Stage 3 — Local Web MVP

日期：2026-10-14（Asia/Shanghai）。**本地 Web MVP 已完成真实浏览器闭环，阶段 3 核心闸门通过。** 本阶段未注册、发布或部署在线网站；部署仍按交接计划留到后续阶段。

## 交付

- `web/index.html`、`styles.css`、`app.js`、自绘 SVG 标识：中文响应式界面，纽约周边主体验、上海实验入口、明确中心与半径、自然语言输入、兴趣示例。
- `src/cityplay/web.py`：沿用现有 Python 核心，标准库本地服务，不新增运行时依赖或重建框架。
- 两步确认：DeepSeek 解析后可修改兴趣、人物/作品类型、场所类别、排除项与必须满足的条件；只有明确确认后才访问推荐链路。
- 同名兴趣选择、真实任务进度、最多 3 张带来源与不确定性的候选卡片、换一批、空结果与失败提示。
- “换一批”排除同一份已确认需求中展示过的 ID；修改条件必须再次确认，不将展示历史伪装成真实到访史。
- 有意义的检查状态保留；没有虚构百分比、价格、营业时间、活动、路线或示例地点替代真实结果。

## 启动

```sh
PYTHONPATH=src python3 -m cityplay.web --port 8787
```

启动后打开 `http://127.0.0.1:8787/`。凭据继续通过项目 `.env.local` 的 Qloo `APIKey`/`QLOO_API_KEY` 与 `DEEPSEEK_API_KEY` 读取，不放入浏览器。

操作：选择城市与范围 → 描述兴趣 → 理解需求 → 确认或修改 → 开始探索 → 查看来源 / 换一批。若有同名候选，先选择正确类型与实体；若要求预算、访问时间或即时营业，未知证据会拦截结果。

初始纽约中心使用官方 Qloo 参数文档的公共示例坐标；上海示例中心由 [Shanghai Basic Facts](https://english.shanghai.gov.cn/assets/Download/2022-ShanghaiBasicFacts.pdf) 的 31°14′ N、121°29′ E 换算。二者都是示例探索中心，不是用户定位或 Qloo 私有响应数据；可自行调整。半径不表示行政市界。

## 真实浏览器验收

使用 Codex 内置浏览器操作页面，访问首页实际 HTTP 200。没有通过注入 fetch 或替代静态 fixture 来冒充页面成功。

| 流程 | 实际结果 |
|---|---|
| 输入文化人物 + 独立书店 + 排除酒店/商场 | DeepSeek v4-pro HTTP 200，输出待确认需求 |
| 修改类型并明确确认 | 3 次真实 Qloo 请求，4 个检索候选，呈现 3 张 partial 卡片 |
| 来源检查 | 3 张卡片中 2 个网站名称可对应，1 个网站不可达，待核验状态保留 |
| 点击换一批 | 返回剩余 1 个，私有缓存来源明确显示，Qloo 新请求 0 次 |
| 明确最高预算 USD 50 并再次确认 | empty；没有用未知费用的候选冒充满足预算的推荐，Qloo 新请求 0 次 |
| 清空实体类型 | 未猜测同名含义，真实 `/search` 1 次后显示选择界面 |
| 选择已返回的音乐人候选并继续 | 返回 3 张卡片，复用缓存，Qloo 新请求 0 次 |
| 合成联系方式输入 | 发送给模型前被本地拦截；页面显示明确提示，无模型/Qloo 新调用 |

本次模型将该文化人物归为 person；确认界面允许显式改为 artist。不能把模型自动理解当成确定事实，这正是保留确认步骤的原因。

真实解析此次 usage 为 422 prompt tokens、125 completion tokens、547 total tokens；未推算费用。实际调用标识与回报模型均为 deepseek-v4-pro。

纽约周边候选可能含相邻城市；页面一直使用“附近/周边”，不声称 NYC 行政区内结果。距离是坐标计算的直线距离，非路线/交通耗时。网站名称匹配不代表分店、营业、预算、活动或公众访问已经确认。

## 本地安全与调用保护

仅绑定 127.0.0.1；只提供明确允许的静态资源，`.env.local`、源码、私有响应和任意文件路径均不能通过网页下载。Cookie 为 HttpOnly/SameSite=Strict，修改请求校验 Origin、Host 与会话 CSRF，任务只能被所属会话读取。

最多 16 个会话、每会话每分钟 6 次操作、同时 2 个任务、每次探索最多 14 个 Qloo 网络尝试、每会话最多 40 次、每进程最多 120 次；进程内统一 Qloo 节奏至少 300ms。缓存为私有内存，Qloo TTL=300s；网站证据可在当前会话复用且一直不作为实时运营证明。

已知的服务 Key 不能作为自然语言或手动兴趣转发；明显联系方式也在模型调用前被拦截。响应与本地证据会移除已知 Key，错误仅暴露安全分类，不返回原始错误体或堆栈。

这些是本地开发保护，不是公开部署的持久配额、用户认证或跨实例速率控制。重启会清空进程预算、任务与缓存；尚未实现全局墙钟取消与断线后任务恢复。第三阶段不对公网开放。
